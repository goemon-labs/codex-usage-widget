# ReCast — AI Usage Widget

Codex・Claude Code・Antigravity CLIの利用枠の残量を、デスクトップで確認できるウィジェットです。
OpenAI・Anthropic・Googleとは関係のない、コミュニティ製の非公式ツールです。

- Codex・Claude Code・Antigravity CLIの残量とリセット日時を表示
- 使っているサービスだけを表示。複数のサービスは1つの画面にまとめて表示
- 上限に達したときは、リセットまでの残り時間を表示
- Codexのリセット権の枚数と有効期限を表示
- Codexは5分ごとに自動で更新。Claude Code・Antigravity CLIは、各ツールの使用中に自動で反映
- カード表示と、残量だけの1行表示を切り替え
- ドラッグで移動、表示位置の保存、最前面表示、ログイン時の自動起動

## 動作環境

| OS | 対象 |
| --- | --- |
| Windows | Windows 11、x64 |
| macOS | macOS 13以降、Apple Silicon／Intel（試験対応） |

macOS版は実機での動作が未検証のため、試験対応です。

表示したいサービスを、あらかじめインストールしておく必要があります。

| サービス | 必要なもの |
| --- | --- |
| Codex | 公式のデスクトップアプリ、またはCodex CLI（コマンドで操作する版）に、ChatGPTアカウントでログイン |
| Claude Code | Claude Code（CLI）に、Pro・Maxプランなど利用枠のあるプランでログイン |
| Antigravity CLI | Antigravity CLIにログイン |

[Codexアプリの導入手順](https://learn.chatgpt.com/docs/quickstart?setup=app) · [Codex CLIの導入手順](https://developers.openai.com/codex/cli/)

Claude CodeはCLIのみに対応しています。ターミナルでの利用、VS Code内のターミナルでの利用が対象です。VS Code拡張やClaudeアプリ内のClaude Codeを利用している際は、リアルタイムでの更新ができません。

## ダウンロードと起動

[Releases](https://github.com/goemon-labs/recast-widget/releases)から、利用するOSに合ったファイルを選びます。

### Windows

1. ファイル名が `windows-x64-setup.exe` で終わるインストーラーを開きます。
2. 画面の案内に沿ってインストールします。デスクトップのショートカットは任意で作成できます。
3. スタートメニューの「ReCast」から起動します。

インストーラー版は、Windowsの「設定」→「アプリ」からアンインストールできます。

ZIP版を使う場合は、`windows-x64.zip` で終わるファイルを展開し、フォルダ内の `recast-widget.exe` を起動します。

以前の「Codex Usage Widget」を使っている場合も、設定と自動起動は引き継がれます。インストーラー版は、そのまま上書きでインストールできます。

### macOS

| Macの種類 | ファイル名の末尾 |
| --- | --- |
| Apple Silicon | `macos-arm64.zip` |
| Intel | `macos-x64.zip` |

ZIPを展開し、「ReCast.app」をアプリケーションフォルダへ移して起動します。

### 初回起動時の警告について

OSの設定や配布ファイルの署名の状態によって、初回起動時に警告や起動制限が表示される場合があります。
表示内容と入手先を確認し、[Windowsの説明](https://support.microsoft.com/ja-jp/windows/security/windows-security/app-browser-control-in-the-windows-security-app)または[Macの説明](https://support.apple.com/ja-jp/102445)を参照してください。

## 基本操作

初めて起動すると、インストール済みのサービスを確認します。Codex以外のサービスも見つかった場合は、表示するサービスを選ぶ画面が出ます。
右上の「⋯」から表示や設定を変更できます。

| やりたいこと | 操作 |
| --- | --- |
| 表示するサービスを変える | 「⋯」→「設定」で、サービスのチェックを入れる・外す |
| まとめた画面から1つのサービスを詳しく見る | サービス名をクリック（左上の「‹」で戻る） |
| 表示位置を変える | カードの文字や余白をドラッグ |
| 残量だけを小さく表示する | 「⋯」→「バーモード」 |
| カード表示に戻す | 「⋯」→「通常表示」 |
| 他のウィンドウより手前に表示する | 「⋯」→「最前面に表示」 |
| パソコンへのログイン時に起動する | 「⋯」→「ログイン時に自動起動」 |
| Codexの残量を今すぐ更新する | カード右下の更新アイコン、または常駐アイコンの「今すぐ更新」 |
| 一時的に画面から隠す | 「⋯」→「隠す」 |
| 隠したウィジェットを表示する | 常駐アイコンの「ウィジェットを表示」、またはアプリをもう一度起動 |
| アプリを終了する | 「⋯」または常駐アイコンの「終了」 |

常駐アイコンは、Windowsでは通知領域（右下の「^」内を含む）、macOSではメニューバーに表示されます。
表示位置と表示モードは次回起動時にも引き継がれます。

Codexの「利用制限のリセット」をクリックすると、チケットごとの有効期限を確認できます。もう一度クリックすると、枚数と期限の表示に戻ります。

## Claude Code・Antigravity CLIとの接続

「⋯」→「設定」でClaude CodeまたはAntigravity CLIにチェックを入れると、そのツールのステータスライン（画面下部の表示欄）に、ReCastへ残量を渡すコマンドを登録します。チェックを外すと、元の設定に戻します。

| サービス | 書き換える設定ファイル |
| --- | --- |
| Claude Code | `~/.claude/settings.json` |
| Antigravity CLI | `~/.gemini/antigravity-cli/settings.json` |

- すでにステータスラインを使っている場合は、その表示がそのまま残ります。
- Claude Codeでステータスラインを使っていなかった場合は、Claude Codeの画面下部に残量が表示されます。
- 残量は、各ツールの使用中に更新されます。しばらく使っていない間は、最後に使ったときの残量を表示します。
- ReCastをアンインストールするときは、先に設定画面でチェックを外してください。

## バー表示のロゴ

バーモードで複数のサービスを表示するときは、サービス名の代わりにロゴを表示できます。
各サービスのロゴ画像を用意して次のフォルダに置き、ReCastを起動し直してください。フォルダがない場合は作成してください。

| OS | フォルダ |
| --- | --- |
| Windows | `%APPDATA%\recast-widget\config\icons` |
| macOS | `~/Library/Application Support/recast-widget/icons` |

ファイル名は `codex.png`・`claude.png`・`antigravity.png` です。正方形で背景が透明な、1辺1024ピクセル以下のPNG画像を使ってください。

## 表示の見方

| 表示 | 意味 |
| --- | --- |
| 残り○% | 各サービスから受け取った情報をもとに計算した残量です |
| ○○の上限に達しました | その枠を使い切りました。大きな数字はリセットまでの残り時間です |
| 前回取得 | Codexの更新に失敗したため、表示時刻に取得した値を表示しています |
| 確認中… | 最新の情報を確認しています |
| まだデータがありません | 接続したツールを使うと、残量が表示されます |
| リセット済み | リセット日時を過ぎました。次に各ツールを使うと、新しい残量に更新されます |

左上の点は、いずれかのサービスが上限に達すると黄色になります。
バーモードでは、Codexの残量を取得できないときも黄色になります。「⋯」→「設定」で接続状況を確認してください。

## 接続に困ったとき

### Codexが見つからない・残量が表示されない

公式CodexのアプリまたはCLIでログインを確認し、ウィジェットの「⋯」→「設定」を開きます。
自動検出で見つからない場合は、「Codexの場所を選択」でインストール済みのCodexを指定してください。

アプリとCLIの両方がある場合、自動検出はCLIを優先します。

### Claude Code・Antigravity CLIの残量が変わらない

残量は、各ツールの使用中に更新されます。Claude Codeは、ターミナルで使ったときに更新されます。
使っても更新されない場合は、「⋯」→「設定」でチェックを外してから、もう一度入れ直してください。

### アカウントを切り替えたい

各ツールでアカウントを切り替えてください。Codexは次の更新から、Claude Code・Antigravity CLIは次に使ったときから、切り替えたアカウントの残量を表示します。

### 各ツールの更新後に表示されなくなった

各ツールの更新により、連携方法が変わる場合があります。[Releases](https://github.com/goemon-labs/recast-widget/releases)でReCastの更新を確認してください。

## データの扱い

ReCastが設定として保存するのは、表示位置・表示モード・最前面表示・選択したCodexの場所・表示するサービスと、接続を解除するときに元へ戻すための各ツールのステータスラインの設定です。保存先はOSのユーザー用アプリ設定フォルダです。
自動起動は、現在のOSユーザーの設定として登録します。

Claude Code・Antigravity CLIから受け取るデータのうち、保存するのは使用率・リセット日時・利用額などの利用枠の情報だけです。メールアドレスや作業中のフォルダなどは保存しません。
接続と解除のときは、各ツールの設定ファイルのステータスラインの項目だけを書き換えます。書き換える前のファイルは、ReCastのデータフォルダ内の `backups` に保存します。

Codexの残量・プラン名・ログイン中のメールアドレスは、起動中のメモリで保持します。
認証情報の保存・更新と、利用枠を取得する通信は、各サービスの公式ツールが担当します。
