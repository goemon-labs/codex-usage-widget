# Codex Usage Widget

Codexの利用枠の残量をデスクトップで確認できる、コミュニティ製のウィジェットです。

- 週次・短時間の残量とリセット日時を表示
- リセット権の枚数と有効期限を表示
- カード表示と、残量だけの1行表示を切り替え
- 通常は5分ごとに自動更新。手動更新とスリープ復帰後の更新にも対応
- ドラッグで移動、表示位置の保存、最前面表示、ログイン時の自動起動

## 動作環境

| OS | 対象 |
| --- | --- |
| Windows | Windows 11、x64 |
| macOS | macOS 13以降、Apple Silicon／Intel（試験対応） |

macOS版は実機での動作が未検証のため、試験対応です。

**Codexを利用できる公式デスクトップアプリ、またはCodex CLI（コマンドで操作する版）をインストールし、ChatGPTアカウントでログインしておく必要があります。**

[公式デスクトップアプリの導入手順](https://learn.chatgpt.com/docs/quickstart?setup=app) · [公式CLIの導入手順](https://developers.openai.com/codex/cli/)

## ダウンロードと起動

[Releases](https://github.com/goemon-labs/codex-usage-widget/releases)から、利用するOSに合ったファイルを選びます。

### Windows

1. ファイル名が `windows-x64-setup.exe` で終わるインストーラーを開きます。
2. 画面の案内に沿ってインストールします。デスクトップのショートカットは任意で作成できます。
3. スタートメニューの「Codex Usage Widget」から起動します。

インストーラー版は、Windowsの「設定」→「アプリ」からアンインストールできます。

ZIP版を使う場合は、`windows-x64.zip` で終わるファイルを展開し、フォルダ内の `codex-usage-widget.exe` を起動します。

### macOS

| Macの種類 | ファイル名の末尾 |
| --- | --- |
| Apple Silicon | `macos-arm64.zip` |
| Intel | `macos-x64.zip` |

ZIPを展開し、「Codex Usage Widget.app」をアプリケーションフォルダへ移して起動します。

### 初回起動時の警告について

OSの設定や配布ファイルの署名の状態によって、初回起動時に警告や起動制限が表示される場合があります。
表示内容と入手先を確認し、[Windowsの説明](https://support.microsoft.com/ja-jp/windows/security/windows-security/app-browser-control-in-the-windows-security-app)または[Macの説明](https://support.apple.com/ja-jp/102445)を参照してください。

## 基本操作

ログイン済みのCodexが見つかると、残量が表示されます。右上の「⋯」から表示や設定を変更できます。

| やりたいこと | 操作 |
| --- | --- |
| 表示位置を変える | カードの文字や余白をドラッグ |
| 残量だけを小さく表示する | 「⋯」→「バーモード」 |
| カード表示に戻す | 「⋯」→「通常表示」 |
| 他のウィンドウより手前に表示する | 「⋯」→「最前面に表示」 |
| パソコンへのログイン時に起動する | 「⋯」→「ログイン時に自動起動」 |
| 今すぐ残量を更新する | カード右下の更新アイコン、または常駐アイコンの「今すぐ更新」 |
| 一時的に画面から隠す | 「⋯」→「隠す」 |
| 隠したウィジェットを表示する | 常駐アイコンの「ウィジェットを表示」、またはアプリをもう一度起動 |
| アプリを終了する | 「⋯」または常駐アイコンの「終了」 |

常駐アイコンは、Windowsでは通知領域（右下の「^」内を含む）、macOSではメニューバーに表示されます。
表示位置と表示モードは次回起動時にも引き継がれます。

「利用制限のリセット」をクリックすると、チケットごとの有効期限を確認できます。もう一度クリックすると、枚数と最短期限の表示に戻ります。

## 表示の見方

| 表示 | 意味 |
| --- | --- |
| 残り○% | Codexから取得した使用率をもとに計算した残量です |
| 前回取得 | 更新に失敗したため、表示時刻に取得した値を表示しています |
| リセット後の情報を確認中 | リセット日時を過ぎ、新しい情報の取得を待っています |
| 週次の情報を取得できませんでした | 接続中のアカウントから週次枠の情報を取得できていません |
| 一部の有効期限を確認中 | リセット権の枚数は取得できていますが、期限の詳細が一部不足しています |

バーモードの点が黄色になった場合は、「⋯」→「設定」で接続状況を確認してください。

## 接続に困ったとき

### Codexが見つからない・残量が表示されない

公式CodexのアプリまたはCLIでログインを確認し、ウィジェットの「⋯」→「設定」を開きます。
自動検出で見つからない場合は、「場所を選択」でインストール済みのCodexを指定し、「接続を確認」を押してください。

アプリとCLIの両方がある場合、自動検出はCLIを優先します。「設定」には接続に使用するCodexが表示されます。

### アカウントを切り替えたい

接続に使用する公式Codex側でアカウントを切り替え、ウィジェットを更新してください。
残量は、そのCodexにログインしているアカウントの情報です。

### Codexの更新後に取得できなくなった

Codexの更新により、連携方法が変わる場合があります。[Releases](https://github.com/goemon-labs/codex-usage-widget/releases)でウィジェットの更新を確認してください。

## データの扱い

ウィジェットの設定として保存するのは、表示位置・表示モード・最前面表示・選択したCodexの場所です。保存先はOSのユーザー用アプリ設定フォルダです。
自動起動は、現在のOSユーザーの設定として登録します。

残量・ログイン中のメールアドレス・プラン名は、起動中のメモリで保持して画面に表示します。
認証情報の保存・更新と、利用枠を取得する通信は公式Codexが担当します。
